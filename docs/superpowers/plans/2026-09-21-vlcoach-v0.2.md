# vlcoach v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI that turns a public Tracker.gg Valorant history into a coaching report where every claim carries an interval, a sample count, and an association-not-causation caveat.

**Architecture:** Six flat modules under `vlcoach/`, dependencies pointing strictly at `config.py`. Deterministic core (`stats`, `clean`, `coach`, `cli`) is built first against synthetic data; the network module (`collect`) comes last behind a module boundary. Every stage reads only the previous stage's file under `data/`.

**Tech Stack:** Python 3.13, `scrapling[fetchers]` (pinned git commit), `numpy`, `scipy`, `scikit-learn`, `pytest`. Everything else stdlib: `argparse`, `urllib.request`, `csv`, `json`.

**Spec:** `docs/superpowers/specs/2026-09-21-vlcoach-design.md` (technical design) implementing `SPECIFICATION.md` (product spec v0.2).

## Global Constraints

- Scrapling `DynamicFetcher` only. Never `StealthyFetcher`, `proxy`, `proxy_rotator`, `useragent`, `real_chrome`, CAPTCHA handling, or Tracker internal API calls. (`CLAUDE.md`, spec §3.2)
- Fail closed on any block: no retry escalation, no automatic `--headed` fallback. (spec §5.3)
- Never fabricate a missing value. Never infer `result` the page did not state. (spec §6.1)
- `k = 10`, `alpha = 0.20`, 2,000 bootstrap resamples, minimum 40 rows with both classes for the model. (spec §7)
- Analysis JSON is the only input to the AI. (spec §8.2)
- Five report headings, in order, both languages. `--lang fr|en`, default `en`. (spec §8.3, `CLAUDE.md`)
- Outputs: `data/raw/<stem>.json`, `data/clean/<stem>.csv`, `data/analysis/<stem>.json`, `data/analysis/<stem>_coach.md`. (spec §10)
- Pace rule from `CLAUDE.md`: one file per step, say what and why first, wait for "ok", show the diff after. Append to `HISTORY.md` after each task. Every file opened for text uses `encoding="utf-8"` (Windows default is cp1252 and French breaks).

```markdown
## 9. Addendum 2026-09-21 — statistics and coaching review

Agreed additions after review. None changes the methods in §4; they add context and honesty around them.

- **Multiple comparisons.** `analyze()` counts every interval it reports and exposes `comparisons: {n, expected_false_positives: n/20}`. A win-vs-loss entry is `signal: true` only when its CI is clear of zero **and** `|diff|` exceeds one MAD of that metric across all matches. The fallback and the prompt both use `signal`, not `uncertain`, to name priorities.
- **Model honesty.** `logistic()` returns `auc_std` across folds. Map and agent one-hot columns enter the model only when there are at least 100 rows with a result (`MIN_CATEGORICAL_ROWS`); below that only the five continuous features are used. The result carries `categorical_used: bool`.
- **Round margin.** `clean()` derives `round_diff = score_a - score_b`. `analyze()` reports the median margin in losses and in wins under `margins`. A player who loses 13-11 and one who loses 13-3 need different coaching.
- **Consistency.** `form[field]` carries `mad`, the MAD already computed for the robust z, as a plain consistency number.
- **Team context.** `parse_match` reads the player's whole team block, not one row, and derives `acs_rank_in_team` (1 = top ACS on the team, 5 = bottom). It is a `FIELDS` entry bounded to [1, 5] and joins the win-vs-loss comparisons.
- **Rank context.** `rr_change` (int, unbounded) is a `FIELDS` entry and `lobby_rank` (string label) a `CONTEXT` entry. Both are optional: the parser records them only when the page shows them; the cleaner never invents them.
- **Wider comparisons.** `DIFF_FIELDS` = `acs, adr, kast_pct, dd_delta, hs_pct, opening_balance, mk, kd, acs_rank_in_team`.
```

```python
"""Spec section 7. Pure functions, None-tolerant. Each answers one question."""
import math

import numpy as np
from scipy import stats as sps

from .config import K, ALPHA, N_BOOT, SEED, MIN_MODEL_ROWS, MODEL_FEATURES, MODEL_CATEGORICAL, FORM_FIELDS

LEAKAGE_WARNING = (
    "ACS, KAST, DD-delta and similar end-of-match metrics are partly consequences of how the match "
    "unfolded. They describe matches; they cannot prove that deliberately maximizing a metric will "
    "cause a win. Every coefficient and difference here is an association, not a causal effect."
)


def _vals(xs):
    return [x for x in xs if x is not None]


def wilson(w, n, z=1.96):
    """95% Wilson score interval. Spec 7.1."""
    if n == 0:
        return None
    p = w / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return [c - h, c + h]


def jeffreys(w, l):
    """Beta(w+0.5, l+0.5) posterior mean and 95% credible interval. Spec 7.2."""
    b = sps.beta(w + 0.5, l + 0.5)
    return {"mean": float(b.mean()), "ci": [float(b.ppf(0.025)), float(b.ppf(0.975))]}


def shrink(wins_g, n_g, p_global, k=K):
    """Empirical-Bayes shrinkage toward the player's overall rate. Spec 7.3."""
    return (wins_g + k * p_global) / (n_g + k)
```

```python
def robust_z(xs):
    """Median/MAD z-score per value, 0.67449 scaling. Spec 7.4. MAD == 0 -> all None."""
    v = _vals(xs)
    if len(v) < 2:
        return [None] * len(xs)
    med, mad = float(np.median(v)), float(sps.median_abs_deviation(v))
    if mad == 0:
        return [None] * len(xs)
    return [None if x is None else 0.67449 * (x - med) / mad for x in xs]


def ewma(xs, alpha=ALPHA):
    """Exponentially weighted moving average; a None carries the previous value. Spec 7.5."""
    out, s = [], None
    for x in xs:
        if x is not None:
            s = x if s is None else s + alpha * (x - s)  # exact on a constant series
        out.append(s)
    return out


def bootstrap_diff(win_vals, loss_vals, n_boot=N_BOOT, seed=SEED):
    """mean(win) - mean(loss) with a 95% match-level bootstrap CI. Spec 7.6."""
    w, l = np.array(_vals(win_vals), float), np.array(_vals(loss_vals), float)
    if len(w) < 2 or len(l) < 2:
        return None
    rng = np.random.default_rng(seed)
    diffs = [rng.choice(w, len(w)).mean() - rng.choice(l, len(l)).mean() for _ in range(n_boot)]
    lo, hi = np.percentile(diffs, [2.5, 97.5])
    return {"diff": float(w.mean() - l.mean()), "ci": [float(lo), float(hi)], "uncertain": bool(lo <= 0 <= hi)}
```

```python
def logistic(rows):
    """L2 logistic regression, win ~ features + map + agent. Spec 7.7. Associations only."""
    empty = {"skipped": None, "auc": None, "auc_std": None, "odds_ratios": {}, "categorical_used": False}
    rs = [r for r in rows if r.get("win") is not None]
    y = [r["win"] for r in rs]
    if len(y) < MIN_MODEL_ROWS:
        return {**empty, "skipped": f"need {MIN_MODEL_ROWS} rows with a result, have {len(y)}"}
    if len(set(y)) < 2:
        return {**empty, "skipped": "only one class present"}
    from sklearn.impute import SimpleImputer
    from sklearn.linear_model import LogisticRegression
    from sklearn.model_selection import StratifiedKFold, cross_val_score
    from sklearn.pipeline import make_pipeline
    from sklearn.preprocessing import OneHotEncoder, StandardScaler

    X = np.array([[np.nan if r.get(f) is None else r[f] for f in MODEL_FEATURES] for r in rs], float)
    names = list(MODEL_FEATURES)
    use_cat = len(y) >= MIN_CATEGORICAL_ROWS   # below this, one-hot columns are noise with 3 obs each
    if use_cat:
        enc = OneHotEncoder(handle_unknown="ignore", sparse_output=False)
        # ponytail: one-hot fit outside CV; harmless for categoricals, move into the pipeline if it ever matters
        cat = enc.fit_transform([[r.get(c) or "unknown" for c in MODEL_CATEGORICAL] for r in rs])
        X = np.hstack([X, cat])
        names += list(enc.get_feature_names_out(MODEL_CATEGORICAL))
    pipe = make_pipeline(SimpleImputer(keep_empty_features=True), StandardScaler(),
                         LogisticRegression(penalty="l2", max_iter=1000))
    folds = min(5, y.count(0), y.count(1))
    auc = auc_std = None
    if folds >= 2:
        scores = cross_val_score(pipe, X, y, cv=StratifiedKFold(folds, shuffle=True, random_state=SEED), scoring="roc_auc")
        auc, auc_std = float(scores.mean()), float(scores.std())
    pipe.fit(X, y)
    coef = pipe[-1].coef_[0]
```

```python
def analyze(rows, quality):
    """Everything the coach reads. Rows must be sorted oldest -> newest."""
    res = [r for r in rows if r.get("win") is not None]
    n, w = len(res), sum(r["win"] for r in res)
    p = w / n if n else None
    out = {
        "quality": quality,
        "leakage_warning": LEAKAGE_WARNING,
        "winrate": {"n": n, "wins": w, "p": p, "wilson": wilson(w, n), "jeffreys": jeffreys(w, n - w) if n else None},
    }
    for key in ("map", "agent"):
        g = {}
        for r in res:
            k = r.get(key) or "unknown"
            g.setdefault(k, [0, 0])
            g[k][0] += r["win"]
            g[k][1] += 1
        out[f"by_{key}"] = {k: {"n": c, "wins": ww, "raw": ww / c, "shrunk": shrink(ww, c, p)} for k, (ww, c) in g.items()}
    out["form"], out["outliers"] = {}, {}
    for f in FORM_FIELDS:
        series = [r.get(f) for r in rows]
        e = ewma(series)
        out["form"][f] = {"ewma": e, "last": next((v for v in reversed(e) if v is not None), None), "mad": _mad(series)}
        out["outliers"][f] = {"z": robust_z(series)}
    out["win_vs_loss"] = {}
    for f in DIFF_FIELDS:
        r = bootstrap_diff([x.get(f) for x in res if x["win"]], [x.get(f) for x in res if not x["win"]])
        if r:
            mad = _mad([x.get(f) for x in res])
            # signal = CI clear of zero AND effect bigger than one MAD of the metric; guards against 1-in-20 flukes
            r["signal"] = (not r["uncertain"]) and mad is not None and abs(r["diff"]) > mad
        out["win_vs_loss"][f] = r
    n_cmp = sum(1 for r in out["win_vs_loss"].values() if r) + len(out["by_map"]) + len(out["by_agent"])
    out["comparisons"] = {"n": n_cmp, "expected_false_positives": n_cmp / 20}
    out["margins"] = {
        "loss_median_round_diff": _median([r.get("round_diff") for r in res if not r["win"]]),
        "win_median_round_diff": _median([r.get("round_diff") for r in res if r["win"]]),
        "acs_rank_in_team_median": _median([r.get("acs_rank_in_team") for r in rows]),
    }
    out["model"] = logistic(rows)
    return out


def _mad(xs):
    v = _vals(xs)
    return float(sps.median_abs_deviation(v)) if len(v) >= 2 else None


def _median(xs):
    v = _vals(xs)
    return float(np.median(v)) if v else None
```

```python
"""Spec section 6. Raw string dicts -> typed rows. Never fabricates, never infers."""
from .config import FIELDS, CONTEXT


def _num(s, typ):
    if s is None:
        return None
    s = str(s).strip().replace("%", "").replace(",", "").replace("+", "")
    try:
        return typ(float(s))
    except ValueError:
        return None


def _bounded(v, lo, hi):
    if v is None or (lo is not None and v < lo) or (hi is not None and v > hi):
        return None
    return v


def clean(raw):
    seen, rows = set(), []
    for m in raw:
        mid = m.get("match_id")
        if m.get("error") or not mid or mid in seen:
            continue
        seen.add(mid)
        f = m.get("fields") or {}
        row = {c: f.get(c) for c in CONTEXT}
        row["match_id"], row["url"] = mid, m.get("url")
        for name, (typ, lo, hi) in FIELDS.items():
            row[name] = _bounded(_num(f.get(name), typ), lo, hi)
        row["score_a"], row["score_b"] = _num(f.get("score_a"), int), _num(f.get("score_b"), int)
        r = (f.get("result") or "").strip().lower()
        row["result"] = r if r in ("win", "loss", "draw") else None
        row["win"] = {"win": 1, "loss": 0}.get(row["result"])
        k, d = row["kills"], row["deaths"]
        row["kd_computed"] = round(k / d, 2) if k is not None and d else None
        fk, fd = row["fk"], row["fd"]
        row["opening_balance"] = fk - fd if fk is not None and fd is not None else None
        sa, sb = row["score_a"], row["score_b"]
        row["round_diff"] = sa - sb if sa is not None and sb is not None else None
        rows.append(row)
    rows.sort(key=lambda r: r.get("timestamp") or "")
    return rows


def quality(raw, rows):
    """Spec 6.3. Completeness is % of parsed rows with a non-None value."""
    n = len(rows)
    return {
        "discovered": len(raw),
        "parsed": n,
        "with_result": sum(r["win"] is not None for r in rows),
        "completeness": {f: (round(100 * sum(r[f] is not None for r in rows) / n, 1) if n else 0.0) for f in FIELDS},
    }
```

```python
- comparisons.expected_false_positives is how many apparent effects are expected by chance. Mention it.
- margins tells you whether losses are close (clutch/mental) or blowouts (fundamentals). Use it.
- form[*].mad is consistency; acs_rank_in_team_median is whether the player carries or is carried. Use both.
Leakage warning: {leakage}
Answer in {lang_name}. Use exactly these five markdown headings, in this order, each written as "## <heading>", nothing before the first:
{headings}"""


def ask_ollama(analysis, model=AUTO_MODEL, lang="en", url=OLLAMA_URL, timeout=600):
    """Markdown report from the local model, or None on any failure. Spec 8.2–8.4."""
    hs = HEADINGS[lang]
    system = GUARDRAILS.format(leakage=analysis.get("leakage_warning", ""),
                               lang_name={"en": "English", "fr": "French"}[lang], headings="\n".join(hs))
    body = json.dumps({"model": model, "stream": False, "messages": [
        {"role": "system", "content": system},
        {"role": "user", "content": json.dumps(analysis)},
    ]}).encode()
    req = request.Request(f"{url}/api/chat", data=body, headers={"Content-Type": "application/json"})
    try:
        with request.urlopen(req, timeout=timeout) as r:
            text = json.load(r)["message"]["content"]
    except (OSError, KeyError, ValueError):
        return None
    return text if all(f"## {h}" in text for h in hs) else None
```

```python
import csv
import json
import os

from . import clean as C, coach as H, stats as S
from .config import AUTO_MODEL, DATA_DIR, riot_id


def paths(stem):
    for d in ("raw", "clean", "analysis"):
        os.makedirs(os.path.join(DATA_DIR, d), exist_ok=True)
    return {
        "raw": f"{DATA_DIR}/raw/{stem}.json",
        "snap": f"{DATA_DIR}/raw/{stem}",
        "clean": f"{DATA_DIR}/clean/{stem}.csv",
        "analysis": f"{DATA_DIR}/analysis/{stem}.json",

    }


def collect(a):

    rid = riot_id(a.player)
    p = paths(rid["stem"])
    raw = G.fetch_all(rid, a.matches, a.headed, p["snap"])
    with open(p["raw"], "w", encoding="utf-8") as f:
        json.dump(raw, f, indent=1)
    errs = [m for m in raw if m.get("error")]
    print(f"discovered {len(raw)}, parsed {len(raw) - len(errs)}, failed {len(errs)}")
    for m in errs:
        print(f"  {m['url']}: {m['error']}")

def analyze(a):

    p = paths(rid["stem"])
    with open(p["raw"], encoding="utf-8") as f:
        raw = json.load(f)
    rows = C.clean(raw)
    with open(p["clean"], "w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=list(rows[0]) if rows else ["match_id"])
        w.writeheader()
        w.writerows(rows)
    out = S.analyze(rows, C.quality(raw, rows))
    with open(p["analysis"], "w", encoding="utf-8") as f:
        json.dump(out, f, indent=1)
    print(f"{out['quality']['parsed']} rows -> {p['analysis']}")


def coach(a):
    rid = riot_id(a.player)
    p = paths(rid["stem"])
    with open(p["analysis"], encoding="utf-8") as f:
        an = json.load(f)
    model = AUTO_MODEL if a.model == "auto" else a.model
    md = H.ask_ollama(an, model, a.lang)
    source = "ollama" if md else "fallback"
    md = md or H.fallback(an, a.lang)
    with open(p["coach"], "w", encoding="utf-8") as f:
        f.write(md)
    print(f"{source} -> {p['coach']}")


def main(argv=None):
    ap = argparse.ArgumentParser(prog="vlcoach")
    sub = ap.add_subparsers(dest="cmd", required=True)
    for name in ("run", "collect", "analyze", "coach"):
        s = sub.add_parser(name)
        s.add_argument("player", help='"Name#TAG"')
        s.add_argument("--matches", type=int, default=50)
        s.add_argument("--headed", action="store_true")
        s.add_argument("--model", default="auto")
        s.add_argument("--lang", choices=("en", "fr"), default="en")
    a = ap.parse_args(argv)
    steps = {"run": (collect, analyze, coach), "collect": (collect,), "analyze": (analyze,), "coach": (coach,)}[a.cmd]
    for step in steps:
        step(a)


if __name__ == "__main__":
    main()
```

```python
"""Spec section 5. The only module that touches the network. DynamicFetcher only — see CLAUDE.md."""
import json
import os
import re
import time

from .config import FIELDS, CONTEXT

BASE = "https://tracker.gg"
BLOCK_MARKERS = ("Just a moment", "Attention Required", "Access denied", "cf-chl", "Sign in to view")
DELAY_S = 3  # polite fixed delay between page loads

# Filled from inspecting the fixtures (Task 10 Step 2). Keys are FIELDS/CONTEXT names.
SELECTORS = {
    "match_link": "a[href*='/valorant/match/']",
    "row_tag": "tr",
    "team_tag": "tbody",  # ancestor of the row that contains exactly the player's team; confirm on the fixture
    # stat cell index within the player's row -> field name; fill from the fixture
    "cells": {},          # e.g. {2: "acs", 3: "kills", 4: "deaths", 5: "assists", 6: "plus_minus", 7: "kd", 8: "dd_delta", 9: "adr", 10: "hs_pct", 11: "kast_pct", 12: "fk", 13: "fd", 14: "mk", 15: "trs"}
    "map": "",            # css for the map name element
    "agent_in_row": "",   # css relative to the row for the agent image/alt or name
    "result": "",         # css for "Victory"/"Defeat"
    "scores": "",         # css for the two team scores, in order
    "timestamp": "",      # css for the <time> element; use ::attr(datetime) if present
    "rr_change": "",      # css for the player's RR delta, if shown; else leave empty
    "lobby_rank": "",     # css for the lobby/average rank label, if shown; else leave empty
}


class BlockedError(Exception):
    """Access control hit. Caller must stop; never retry-escalate."""


class ParseError(Exception):
    """DOM did not contain what the parser expects. Caller logs and continues."""


def parse_profile(page):
    seen, out = set(), []
    for href in page.css(f"{SELECTORS['match_link']}::attr(href)").getall():
        u = href if href.startswith("http") else BASE + href
        if u not in seen:
            seen.add(u)
            out.append(u)
    if not out:
        raise ParseError("no match links on profile page")
    return out


def parse_match(page, rid):
    cell = page.find_by_text(rid["name"], partial=True)
    row = cell.find_ancestor(lambda e: e.tag == SELECTORS["row_tag"]) if cell else None
    if row is None:
        raise ParseError(f"player {rid['name']!r} not found on scoreboard")
    cells = [c.get_all_text(strip=True) for c in row.css("td")]
    out = {name: cells[i] for i, name in SELECTORS["cells"].items() if i < len(cells) and cells[i]}
    # team context: rank the player's ACS among the 5 rows of their own team block
    acs_i = next((i for i, n in SELECTORS["cells"].items() if n == "acs"), None)
    team = row.find_ancestor(lambda e: e.tag == SELECTORS["team_tag"])
    if acs_i is not None and team is not None and out.get("acs"):
        team_acs = []
        for tr in team.css(SELECTORS["row_tag"]):
            tds = [c.get_all_text(strip=True) for c in tr.css("td")]
            try:
                team_acs.append(float(tds[acs_i].replace(",", "")))
            except (IndexError, ValueError):
                pass
        if 2 <= len(team_acs) <= 5:
            mine = float(out["acs"].replace(",", ""))
            out["acs_rank_in_team"] = str(1 + sum(a > mine for a in team_acs))
    for key in ("map", "result", "timestamp", "rr_change", "lobby_rank"):
        if SELECTORS[key]:
            v = page.css(SELECTORS[key]).getall()
            if v:
                out[key] = v[0].strip()
    if SELECTORS["agent_in_row"]:
        v = row.css(SELECTORS["agent_in_row"]).getall()
        if v:
            out["agent"] = v[0].strip()
    if SELECTORS["scores"]:
        v = page.css(SELECTORS["scores"]).getall()
        if len(v) >= 2:
            out["score_a"], out["score_b"] = v[0].strip(), v[1].strip()
    m = re.search(r"/valorant/match/([0-9a-f-]+)", page.url or "")
    if m:
        out["match_id"] = m.group(1)
    if not out.get("acs") and not out.get("kills"):
        raise ParseError("player row found but no stat cells parsed — selector drift?")
    return out


def _fetch(url, headed):
    from scrapling import DynamicFetcher
    r = DynamicFetcher.fetch(url, headless=not headed, network_idle=True, timeout=60000)
    head = str(r.html_content)[:5000]
    if r.status in (403, 429) or any(mk in head for mk in BLOCK_MARKERS):
        raise BlockedError(f"HTTP {r.status} at {url} — automated access blocked; stopping (spec 5.3)")
    return r


def _snap(snap_dir, name, html):
    os.makedirs(snap_dir, exist_ok=True)
    with open(os.path.join(snap_dir, name), "w", encoding="utf-8") as f:
        f.write(str(html))


def fetch_all(rid, n, headed, snap_dir):
    """Profile -> up to n match pages. Snapshots written before parsing. Partial results on per-match failure."""
    prof = _fetch(BASE + rid["url_path"] + "/matches?playlist=competitive", headed)
    _snap(snap_dir, "profile.html", prof.html_content)
    urls = parse_profile(prof)[:n]
    out = []
    for i, u in enumerate(urls):
        time.sleep(DELAY_S)
        mid = u.rsplit("/", 1)[-1]
        rec = {"url": u, "match_id": mid, "fields": {}, "error": None}
        try:
            page = _fetch(u, headed)
            _snap(snap_dir, f"{mid}.html", page.html_content)
            rec["fields"] = parse_match(page, rid)
        except ParseError as e:
            rec["error"] = f"ParseError: {e}"
        out.append(rec)
        print(f"[{i + 1}/{len(urls)}] {mid} {'ok' if rec['error'] is None else rec['error']}")
    return out
```

`BlockedError` is deliberately not caught inside the loop: it propagates, `cli.collect` never gets to write partial JSON for a block mid-run, and that is fine — the snapshots already on disk are the evidence. If you want the partial raw file on a block, wrap the loop body's `_fetch` in `try/except BlockedError` that writes `out` and re-raises; do that only if it happens in practice.
